# DX12 后端与资源绑定

渲染后端为 `BACKEND_DX12`，使用 Windows SDK 的 D3D12、DXGI、D3DCompiler，以及 ImGui DX12/Win32 后端。
Debug 构建启用 DX12 调试层，Release 构建执行常规渲染与优化后的 Shader 编译。

```powershell
xmake build -a
xmake run utest "[dx12]"
xmake run utest
```

## 管线布局和集合

光栅化以屏幕上的逆时针三角形为正面。场景导入按实例变换确定网格索引的绕序，Mesh 在序列化边界转换为原有归档顺序。

`RHIRootSignatureInfo` 是实际管线布局，可以从编译后的 Shader 反射生成，也可以显式 `add_entry`。相同资源的多阶段可见性会合并。

- `set` 对应 HLSL `spaceN`；现有 SM5.0 Shader 使用 space0。
- `binding` 是寄存器起点，`size` 是数组长度，`index` 是数组内元素。
- CBV/SRV/UAV/Sampler 使用独立命名空间，所以 b0/t0/u0/s0 可以共存。Texture 和 Buffer SRV 共用 t 命名空间。
- 布局检查数组重叠、set 越界及 64 DWORD root 预算；集合检查类型、数组索引和 buffer 范围。
- push constants 显式指定大小、阶段、binding/set；同一个 b 寄存器不能再声明 CBV。

```cpp
RHIRootSignatureInfo layout;
layout.add_entry_from_reflect(vertex_shader);
layout.add_entry_from_reflect(fragment_shader);
auto root = backend->create_root_signature(layout);
auto resources = root->create_descriptor_set(0);
resources->write_buffer(0, per_frame_buffer); // b0
resources->write_texture(0, albedo_texture);  // t0
resources->write_sampler(0, sampler);         // s0
cmd->set_graphics_pipeline(pipeline); // pipeline 使用 root
cmd->bind_descriptor_set(resources, 0);
cmd->draw(3, 1, 0, 0);
```

RHI 命令列表不再暴露 `bind_constant_buffer`、`bind_texture`、`bind_rw_texture`、`bind_sampler`。材质和 Pass 必须通过 DescriptorSet 绑定。

集合持有资源引用；绑定捕获快照，延迟命令不会读到后续集合修改。DX12 常量数据复制到 256 字节对齐的上传分配中，同一个 CPU 常量缓冲可以在 draw 之间更新。提交引用的资源、上传缓冲和 shader-visible 描述符在 GPU fence 完成后才释放或复用。

Device 按纹理、格式、View 类型和 mip/layer/aspect 范围复用 TextureView 对象，纹理只保存弱引用，View 仍持有实际纹理。同一提交内，单元素纹理与 Sampler 表复用已复制的 shader-visible 描述符；每次访问仍执行所需状态转换和 UAV barrier。常量快照不共享可变 CPU 数据。

## RenderGraph

Pass 通过 `.root_signature(root)` 指定布局，通过 `.read()` / `.read_write()` 声明依赖。RDG 创建 DescriptorSet 并填充图资源；回调在设置管线后绑定 `context.descriptors[set]`。也可用 `.descriptor_set(set, resources)` 提供集合，RDG 填充图资源，回调补充材质/对象数据。

Buffer `.read()` 默认是 uniform buffer；读 StructuredBuffer/ByteAddressBuffer 时显式传最后一个参数 `RESOURCE_TYPE_BUFFER`。`.read_write()` 为 UAV buffer。

池化集合重新分配时清除旧资源。仅 Shader 读写边分配描述符；附件、copy、present 边只负责依赖与状态。DX12 按 mip/layer 跟踪真实纹理状态，连续 UAV 访问插入 UAV barrier，只读深度与 SRV 使用组合状态。

上传和回读保持 RHI 紧密排列数据约定，内部通过 `GetCopyableFootprints` 处理行间填充。mip 生成支持 2D/数组/Cube；sRGB 使用 typeless 资源、sRGB SRV 和 UNORM UAV，并在写入时编码 sRGB。

静态 Mesh 的顶点和索引缓冲位于 DEFAULT heap。初始化数据通过上传缓冲复制，上传缓冲在提交 fence 完成后释放。

## 标准间接命令

`RHICommandList::draw_indexed_indirect(RHIIndirectDrawInfo)` 与 `draw_indirect(info)` 支持 GPU CountBuffer、最大命令数、64 位参数/计数偏移及可选 padded stride；不提供计数缓冲时执行指定的最大数量，stride=0 使用标准参数大小。DX12 按命令类型与 stride 缓存 Signature，并保留参数、计数 Buffer 到提交 fence 完成。`dispatch_indirect()` 继续使用标准三个 uint 参数。RDG 中必须声明对应 `.indirect_read()`。

`[gpu_driven]` 功能测试覆盖 GPU 生成参数、计数为零/多个/超过上限、非零偏移、不同 stride 和即时/延迟命令列表。场景入口与第一阶段限制见 [gpu_driven.md](gpu_driven.md)。

## 隐藏窗口与截图

测试设置 `StartMode::HiddenWindow`，创建隐藏 HWND，关闭编辑器 UI，使用真实 GPU 与交换链。

```cpp
std::vector<uint8_t> rgba;
Extent2D extent;
if (EngineContext::render_system()->capture_frame(rgba, extent)) {
    test_utils::save_screenshot_png("build/test-results/frame.png",
                                    extent.width, extent.height, rgba);
}
```

`capture_frame` 读取刚完成的帧，不会误读 Present 后选中的下一张缓冲。`RenderTestApp` 自动保存到 `build/test-results/<scene-name>.png`，可用 `Config::screenshot_path` 覆盖。尺寸来自实际目标。测试应断言截图成功并检查像素，不能依赖编辑器 UI 亮度。

`test/render/test_dx12.cpp` 覆盖 compute/render/copy、描述符池复用、常量与集合快照、register space、描述符数组、奇数行宽传输、mip/array，以及隐藏窗口 Present 后的截图。

## 首版范围

Graphics/compute/transfer 共用一条 direct queue。Device 准备 RDG 批次后并行录制，每个 CommandContext 持有独立的原生命令列表和 allocator；Device 按 RDG 顺序统一提交并 Signal 帧 fence。帧上下文只执行图规划的 barrier，不在绑定时做隐式转换。Immediate `submit_pending()` 提交上传但不等待完成；`flush()`、读回和 Queue `wait_idle()` 保持同步语义。

提交使用三个按 fence 保护的临时资源区间，帧提交和资产上传批次共用这三个区间。共享 shader-visible heap 为每个区间保留独立描述符范围，ImGui 的持久描述符区不参与轮换；64 MiB 动态上传缓冲也分为三个约 21.3 MiB 的区间。达到区间容量时分配失败。资产加载时多张纹理和多个 Mesh 可以共用一个区间，贴图和静态几何的独立 staging 分配随该批次的 fence 回收。只有复用区间、复用 allocator、显式等待或 Present 节流时才等待。读回整理回调按实际提交 fence 顺序处理，即使另一个上下文仍在录制，已完成的读回也可访问。

RDG 在帧末将 back buffer 交接到 `PRESENT`。非 RDG 调用仍可直接使用 swapchain 的 `present()` 兼容路径。当前保留 `Present(1,0)` 的同步间隔，不使用异步多队列或 DXR。Depth bias 使用 PSO 中的 rasterizer state，线宽仅支持 1。

实现参考：[Microsoft Root Signatures](https://learn.microsoft.com/en-us/windows/win32/direct3d12/root-signatures-overview)、[GetCopyableFootprints](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/nf-d3d12-id3d12device-getcopyablefootprints)。
